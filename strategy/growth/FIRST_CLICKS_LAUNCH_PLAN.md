# First Clicks Launch Plan (Reddit, X, Medium)

## Goal

Generate first qualified users for the open-source repo and website.

## Positioning Statement

Open-source paper-to-EPUB workflow focused on high-fidelity layout preservation for technical paper reading on e-readers.

## Channel Plan

### Reddit

- Post where paper-reading and e-reader pain is discussed.
- Lead with problem/learning, not promotion.
- Include one concrete before/after result.
- Ask for edge-case PDFs for feedback loop.

### X (Twitter)

- Use short build-in-public threads.
- Post one technical insight + one visual proof each time.
- Link to repo for reproducibility and site for quick try.

### Medium

- Publish 2 to 4 practical articles:
  - Why PDF papers break on e-readers
  - Reflow vs high-fidelity tradeoffs
  - What changed in your modified k2pdfopt
  - Side-by-side outputs on difficult papers

## 4-Week Cadence

Week 1:
- announce repo
- publish one comparison post
- publish one short Reddit case-study post

Week 2:
- publish technical Medium article
- run before/after X thread
- collect first user pain points

Week 3:
- publish update with fixes and new examples
- share one workflow tutorial (CLI + output)

Week 4:
- publish "what worked / what failed" transparency post
- summarize metrics and next roadmap

## Simple Metrics Dashboard

- Clicks by source: Reddit / X / Medium / Organic
- Repo stars and issues opened
- Website conversion starts
- Completed conversions
- Cost per conversion (if compute is paid)

## Early Messaging Templates

1. "I built an open-source way to make academic PDFs actually readable on e-readers without wrecking layout. Looking for hard test files."
2. "Most converters optimize for text extraction. I optimized for paper reading fidelity. Here are before/after outputs."
3. "Shipped a modified k2pdfopt with stretch controls and a reproducible pipeline. Feedback welcome."
