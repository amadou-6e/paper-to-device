# Strategy

This folder contains competition analysis, SEO plans, monetization experiments, and launch distribution plans.

## Folder Layout

- `competition/` - competitor categories, strengths/weaknesses, differentiation
- `seo/` - keyword map, landing pages, AdSense experiment design
- `growth/` - launch and content distribution for Reddit, X, and Medium

## Current Strategic Direction

1. Open-source first: publish modified `k2pdfopt` and implementation workflow.
2. Validate demand with a lightweight website.
3. Run SEO + AdSense experiments for click and revenue signal.
4. Seed first traffic via Reddit, X, and Medium.
